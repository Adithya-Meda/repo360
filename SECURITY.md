# Security Policy

## Reporting a Vulnerability

Repo360 is maintained as an independent open-source project by Adithya Meda. If you discover a vulnerability, please report it responsibly rather than opening a public issue.

### Preferred Reporting Method
Submit an advisory via **[GitHub Private Vulnerability Reporting](https://github.com/Adithya-Meda/repo360/security/advisories/new)**.

### What to Include
Please provide:
* Detailed description of the vulnerability and attack vector.
* Minimal steps or script to reproduce the issue.
* Potential impact on credentials, tokens, or audit data.
* Any proposed mitigations or remediations.
