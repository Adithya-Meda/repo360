AFTER: Type-Guarded Pagination
def paginate(self, org: str, path: str, params: Optional[Dict[str, Any]] = None) -> Iterator[Dict[str, Any]]:
    url: Optional[str] = path
    query: Optional[Dict[str, Any]] = {**(params or {}), "per_page": 100}
    while url:
        resp = self._send("GET", url, org=org, params=query)
        if resp.status_code in EMPTY_RESOURCE_STATUSES:
            return
        resp.raise_for_status()
        data = resp.json()
        if isinstance(data, list):
            yield from data
        elif isinstance(data, dict):
            logger.warning("paginate received dict response from %s instead of list: keys=%s", url, list(data.keys()))
        url, query = self._next_url(resp), None

GitHub Platform Limitations Disclosed Upfront

Platform Limitation Disclosures:

  • Organization SAML SSO Inspection: GitHub restricts SAML SSO IdP configuration inspection to GitHub Enterprise Cloud accounts with GraphQL organization administration access. Team and Free plans do not have SAML capabilities. Repo360 gracefully detects plan tier and evaluates 2FA requirements as a security baseline.
  • Organization Repository Rulesets: Centrally defined organization-level rulesets require GitHub Enterprise Cloud or an Organization Administration Write token. For organizations without rulesets, Repo360 surfaces actionable remediation commands and policy templates.
  • GitHub Actions Log & Run Retention: Workflow runs older than organization retention limits (default: 90 days) are pruned by GitHub's backend. DORA calculation adapts dynamically to available telemetry and captures pre-window baselines without data loss.
  • Secret Scanning Push Protection: Secret Scanning Push Protection is available natively for public repositories and requires GitHub Advanced Security (GHAS) licenses on private enterprise repositories.
