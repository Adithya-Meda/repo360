# Security Policy

## Supported Versions

Only the latest release receives security patches and updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

Repo360 is maintained as an independent open-source project by Adithya Meda. If you discover a vulnerability, please report it responsibly rather than opening a public issue.

### Preferred Reporting Method
Submit an advisory via **[GitHub Private Vulnerability Reporting](https://github.com/Adithya-Meda/repo360/security/advisories/new)**.

### What to Include
Please provide:
* Detailed description of the vulnerability and attack vector.
* Minimal steps or script to reproduce the issue.
* Potential impact on credentials, tokens, or audit data.
* Any proposed mitigations or remediations.

### Coordinated Disclosure Process
1. **Acknowledgment:** Reports are reviewed directly by the maintainer as promptly as feasible.
2. **Assessment:** The vulnerability will be investigated, severity assessed, and you will be kept informed of progress.
3. **Patch & Release:** A patched release will be published to PyPI and GitHub Releases.
4. **Public Disclosure:** A security advisory will be published with credit given to the finder (unless anonymity is requested).
